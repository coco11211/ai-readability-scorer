# Application Icon

To build the production version of this application, you need to provide an application icon.

## Required Files

Place the following file in this directory:
- `icon.ico` - Windows icon file (256x256 pixels recommended)

## Creating an Icon

You can create an icon using:
1. Online converters (e.g., convertio.co, icoconvert.com)
2. GIMP (free, open-source image editor)
3. Adobe Photoshop
4. Icon creation tools like IcoFX

## Recommended Specifications

- Format: ICO
- Size: 256x256 pixels
- Color depth: 32-bit with alpha channel
- Multiple resolutions included: 16x16, 32x32, 48x48, 256x256

## Temporary Icon

For testing purposes, the build process will use a default Electron icon if this file is missing.
However, for production releases, you should always provide a custom icon.
